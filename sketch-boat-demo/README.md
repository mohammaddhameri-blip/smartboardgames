# Sketch Boat — playable demo v0.1

Standalone browser prototype of the Sketch Boat drawing-and-racing concept.

**Play:** https://mohammaddhameri-blip.github.io/smartboardgames/sketch-boat-demo/

Currently includes freehand hull drawing, simplified physics characteristics, four automatic racers, track difficulty, race timings, and an early wind-driven sailing test. Drawing uploads are tracing references only; automatic photo cleanup and full realistic sailing mechanics are not implemented. The repo also contains a separate work-in-progress `sketch-boat/` v1.0 page, which is not yet playable because its external assets are absent. This v0.1 demo is self-contained and kept separate so work in progress is not overwritten.
